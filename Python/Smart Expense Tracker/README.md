# Smart Expense Tracker

A personal finance management application built with Python, Java, and SQL.

## Features

- Record income and expenses
- Categorize transactions
- Calculate monthly income, spending, and savings
- Store transactions in SQLite
- Export transaction history to CSV
- Validate user input
- Automated unit tests

## Tech Stack

- **Python:** Expense tracking and analytics
- **Java / Spring Boot:** Planned REST API
- **SQLite:** Local persistence
- **PostgreSQL:** Planned shared production database
- **Git and GitHub:** Version control

## Getting Started

### Requirements

- Python 3.10 or newer

### Run the application

```bash
python expense_tracker.py
```

### Run tests

```bash
python -m unittest -v
```
