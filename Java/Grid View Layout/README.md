# GridViewLayoutDemo

## Android Practical 07

Create an Android application working with GridView Layout.

## Objective

To create a GridView containing multiple fruit items arranged in two columns.

## Fruits Used

- Apple
- Banana
- Cherry
- Grapes
- Mango
- Orange

## Concepts Used

- GridView
- Custom GridView Item
- BaseAdapter
- ImageView
- TextView
- LayoutInflater
- Array of Strings
- Array of Drawable Resources

## Project Structure

│                   ├── colors.xml
│                   └── themes.xml

## Expected Output

The application displays the title "Fruits Grid" followed by
six fruits arranged in a 2-column grid.
