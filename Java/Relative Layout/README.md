# Relative Layout Android App

A basic Android application demonstrating how to use `RelativeLayout` to position UI elements relative to one another.

## 📱 Description

This application contains a simple login screen with:

- Welcome title
- Username input field
- Password input field
- Login button

The Login button validates the entered username and password and displays a Toast message.

## 🛠️ Technologies Used

- Java
- XML
- Android Studio
- RelativeLayout
- EditText
- TextView
- Button
- Toast
