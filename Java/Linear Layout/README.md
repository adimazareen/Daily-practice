# Linear Layout Demo

A basic Android application demonstrating the use of `LinearLayout` in Android.

## 📱 Description

This project demonstrates how to create a simple email/message-style interface using a vertical `LinearLayout`.

The application contains:

- To field
- Subject field
- Message field
- Send button

When the user clicks the Send button, the application validates the fields and displays a Toast message.

## 🛠️ Technologies Used

- Java
- Android
- XML
- Android Studio
- LinearLayout
